Deep Boltzmann Machine

A Deep Boltzmann Machine (DBM) is a generative, energy-based model composed of stacked Restricted Boltzmann Machines (RBMs). Unlike feed-forward networks, DBMs learn a joint probability distribution over inputs and hidden representations — enabling both feature learning and generation of new samples.

Key Equations

Energy function
E(v,h) = -v²Wh − b²v − c²h
Conditional P(h|v)
P(h_j=1 | v) = sigmoid( c_j + Σ_i v_i W_ij )
Conditional P(v|h)
P(v_i=1 | h) = sigmoid( b_i + Σ_j h_j W_ij )
CD-k weight update
ΔW = η · ( ⟨vh⟩_data − ⟨vh⟩_model )
Mean-field update
μ_i ← sigmoid( 2W·v + W'²·μ_{i+1} + c ) [DBM positive phase]
Free energy
F(v) = −b²v − Σ_j log(1 + exp(c_j + W_j·v))
Recon. MSE
MSE = (1/N) Σ ||x − decode(encode(x))||²

🔷 Restricted Boltzmann Machine

An RBM is a two-layer undirected graphical model with visible units v and hidden units h. The “restricted” means no intra-layer connections.

  • Visible ↔ Hidden: fully connected
  • No visible–visible or hidden–hidden edges
  • Trained with Contrastive Divergence (CD-k)
  • Momentum SGD with L2 weight decay

🔸 Deep Boltzmann Machine

A DBM stacks multiple RBMs. All layers are undirected — inference propagates both upward and downward, capturing higher-order correlations.

  • Greedy layer-wise pre-training (RBM style)
  • Global refinement via mean-field variational inference
  • Negative phase sampled by Persistent CD (PCD)
  • Bottom layer weights doubled (DBM convention)

⚙️ Contrastive Divergence (CD-k)

CD-k approximates the intractable log-likelihood gradient by running only k Gibbs steps from the data distribution instead of to convergence.

  • Positive phase: clamp v to data, sample h
  • Negative phase: run k Gibbs steps
  • Update: ΔW ∝ ⟨vh⟩_0 − ⟨vh⟩_k
  • k=1 works well in practice (fast convergence)

📊 Evaluation Metrics

The model is evaluated by encoding validation data up through all layers, then decoding back to pixel space and computing the Mean Squared Error (MSE).

  • Pre-train MSE: quality after greedy pre-training
  • Fine-tune MSE: quality after global fine-tuning
  • Improvement %: gain from fine-tuning phase
  • Lower MSE = better reconstruction quality
